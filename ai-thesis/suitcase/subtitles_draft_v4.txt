# 右边墙上打印的字 v4（对方的视角，几次住宿合成的"缩影"）。草稿，可改。
# VOICE: MAIN = 主角（天真好奇，童声，白色大字） ADULT = 大人谈钱（灰色小字，不出声） PHONE = 隔着墙听到的电话（淡青色，只有一半）
# TYPE : A = 我确定听到的原话（实线）  B = 只记得大意（淡）  C = 想象/合成（虚线）
# WHEN : CALM = 平静时慢慢打出  INVADE = 入侵时（声音越过墙，更清楚）；按顺序走，走完循环

CALM   | ADULT | C | 能补贴点开销。

CALM   | MAIN  | A | 她出门了！                                # 原话（中文）
CALM   | MAIN  | C | 她把什么东西放进冰箱了……我好好奇。
