# 行李箱 | 隔音棉 | 床头柜 —— 元素清单（2026-10-27 草稿）

## 摆放（一台投影机，在前面，两边并排）
- 左：行李箱（我）。盖子 = 投影区；旁边挂一个**空白面具**（平时什么都没有）。
- 中：隔音棉（之后再定）。
- 右：床头柜（现在先用盒子代替）。上面是一张一直变化、嘴巴不停开合的脸 + 打印出来的文字；还可以放电话、照相机（只做成象征物，不写成对某个人的指控）。
- 声音：音响藏在行李箱下面 / 床头柜抽屉里。

## 两种状态
1. 平静（大部分时间）
   - 左盖子：慢慢换的简笔画卧室（bedroom_1/2/3.png，每个房间里都有同一个行李箱 = 一直在搬家）
   - 左面具：空白
   - 右：脸一直变、嘴一直动、文字一行行打印；声音又小又闷（像隔着墙）
2. 入侵（偶尔，约 15–25 秒）
   - 右边的声音变清楚、变大
   - 右边那张变化的脸，投到左边空白面具上
   - 左盖子：卧室碎掉，变成万花筒（精神状态被打乱）
   - 可选：背后偶尔出现眼睛 / 天使，放大缩小
   - 然后慢慢退回平静

## 现有东西怎么用
| 现有的 | 新的用途 |
|---|---|
| 万花筒长方形（已 map 到盖子上） | 入侵时的盖子画面 |
| bedroom_1/2/3.png（新画的） | 平静时的盖子画面，慢慢交叉淡入淡出 |
| Lucy 脸池 / 脸图集 | 右边一直变的脸；入侵时同一张脸出现在左面具上 |
| 嘴部开合效果（mouth_warp_shader） | 右边的脸说话（改成跟声音大小走） |
| 眼睛 / 天使 | 入侵时背后偶尔出现（可选） |
| 字幕文字 | 右边打印出来的文字（A 实线 / B 淡 / C 虚线） |
| macOS say 声音（童声 Junior 等） | 右边说话的声音，提前生成好音频 |
| 标准脸、偏差值、棋盘、巨大人脸、拼脸、手戳 | 先不用（另一个故事） |

## 底线
- 脸全是 AI 生成的成年人脸，不做儿童脸，不用程序判断性别/年龄，不存观众的脸。
- 声音是合成的，不用任何真人录音。
- 不出现姓名、地址、房源、学校名、照片。
- 只把确定听到的话当作"原话"；推测一律标成"也许"。
- 展出前问一下导师有没有伦理流程。
